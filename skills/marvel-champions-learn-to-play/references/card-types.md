# Card Types

Covers every player-card and encounter-card type and what each one does when it enters play, plus
aspects and basic cards.

**Referenced by:** SKILL.md | **Card layout and numbered fields:** `marvel-champions-rules-reference/resources/card-anatomy.md`

---

## Player Cards

| Type              | Description                                                                                        |
| ----------------- | -------------------------------------------------------------------------------------------------- |
| **Identity Card** | Double-sided: Hero side / Alter-Ego side. Not counted as part of the deck.                         |
| **Ally**          | Enters play in player's area. Can attack or thwart (takes consequential damage). Max 3 per player. |
| **Upgrade**       | Enters play in player's area. Provides ongoing bonuses or abilities.                               |
| **Support**       | Enters play in player's area. Provides ongoing effects.                                            |
| **Event**         | Played from hand; resolve effect, then discard.                                                    |
| **Resource**      | Used to generate resources when paying costs.                                                      |

## Encounter Cards

| Type            | Description                                                                                  |
| --------------- | -------------------------------------------------------------------------------------------- |
| **Villain**     | Sequential stage cards representing the villain.                                             |
| **Main Scheme** | Represents villain's primary goal.                                                           |
| **Side Scheme** | Secondary schemes that enter play from encounter deck.                                       |
| **Minion**      | Enemy that engages with a player.                                                            |
| **Treachery**   | One-time effect; discarded after resolution.                                                 |
| **Attachment**  | Attaches to the villain or other targets.                                                    |
| **Obligation**  | Hero-specific card shuffled into encounter deck; given to the relevant player when revealed. |

## Identity-Specific Cards

- Each hero has a set of cards **only used in their deck**.

## Aspect Cards

- Four aspects: **Aggression** (red), **Justice** (yellow), **Leadership** (blue/purple), **Protection** (green).
- A player may include cards from **exactly one** aspect in their deck.

## Basic Cards

- Can be included in **any player deck**, regardless of chosen aspect.
