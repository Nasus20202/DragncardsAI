# Marvel Champions — Deck Customization

**Source:** Rules Reference v1.7 | **Referenced by:** SKILL.md

---

## PLAYER DECK RULES

| Rule                          | Requirement                                                                                                                                                                             |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Identity**                  | Exactly **one** identity card                                                                                                                                                           |
| **Deck size**                 | Minimum **40 cards**, maximum **50 cards**                                                                                                                                              |
| **Count exclusions**          | The identity card and any cards with the **permanent** keyword are **not** counted toward deck size                                                                                     |
| **Identity-specific cards**   | Must include **each** identity-specific card associated with the chosen identity, in the **exact quantity** specified by that identity set                                              |
| **Aspect**                    | Choose exactly **one** aspect (Justice, Aggression, Protection, Leadership, or 'Pool); the remainder of the deck is customized with cards that belong to that aspect and/or basic cards |
| **Non-unique card copies**    | No more than **three copies (by title)** of each non-unique card                                                                                                                        |
| **Unique card copies**        | No more than **one copy (by title)** of each unique card among the cards in the deck and the identity card                                                                              |
| **Unique subtitles**          | If two unique cards share the same title but their **subtitles or alter-ego titles differ**, they may coexist in the deck                                                               |
| **Deckbuilding requirements** | Any "deckbuilding requirements" printed on the player's identity card **must be followed**                                                                                              |

## CLASSIFICATIONS

A card's classification is the group that a card belongs to, as determined by its specific attributes.

| Classification            | Description                                                                                                                           | Deckbuilding Rule                                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Identity-specific**     | Cards belonging to an identity's set; designated by the identity icon in the bottom right corner                                      | Must include each identity-specific card in the exact quantity specified |
| **Aspect**                | Cards belonging to Aggression, Justice, Leadership, Protection, and/or 'Pool; designated by the aspect name at the bottom of the card | Can include cards from the single chosen aspect                          |
| **Basic**                 | Cards not associated with a specific identity or aspect; designated by the word "Basic" at the bottom of the card                     | Can include in any deck regardless of chosen aspect                      |
| **Scenario-specific**     | Cards belonging to a scenario's set                                                                                                   | Cannot be included in player decks                                       |
| **Modular encounter set** | Cards belonging to a modular set of encounter cards                                                                                   | Cannot be included in player decks                                       |
| **Campaign-specific**     | Cards usable only during a specific product's campaign                                                                                | Can only be used during a campaign from the same product                 |
| **Standard**              | Cards added to most scenarios                                                                                                         | Encounter cards; cannot be included in player decks                      |
| **Expert**                | Cards added to scenarios in expert mode                                                                                               | Encounter cards; cannot be included in player decks                      |

## ENCOUNTER DECK RULES

Each scenario comes with a **recommended list of card sets** forming the default encounter deck (for the core set scenarios, these lists are in the Learn to Play book).

### Customization Options

| Option                    | Rule                                                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Expert mode**           | Use the listed expert mode villain stages; add the Expert encounter set to the encounter deck                                              |
| **Swap modular sets**     | Remove the default modular encounter set(s) from the list and add any other modular encounter set(s) as desired                            |
| **Multiple modular sets** | Possible to add multiple modular sets to a scenario, but this will **dilute** the encounter deck if too many are added                     |
| **Uncertainty option**    | The modular set may be chosen from a group of **facedown sets** and shuffled directly into the encounter deck without looking at the cards |

### Encounter Set Types

| Type                                 | Notes                                                                                                                                     |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Scenario-specific encounter sets** | Tied to a specific scenario; cannot be mixed                                                                                              |
| **Modular encounter sets**           | Can be added to and/or removed from nearly any scenario; always added as an **entire set** unless specific scenario rules state otherwise |
| **Standard set**                     | Added to most scenarios; **not** a modular encounter set; cannot be selected when a scenario requires choosing a modular set              |
| **Expert set**                       | Added during expert mode; **not** a modular encounter set; cannot be selected when a scenario requires choosing a modular set             |

## UNIQUE CARD RULES (DECKBUILDING)

Two unique cards **match** if any of the following apply:

- They share a title, and both have no subtitle and no alter-ego title.
- The subtitle or alter-ego title of one matches the title, subtitle, or alter-ego title of the other.

**Deckbuilding impact:**

- A player cannot include multiple matching cards in their deck. The **identity card is included** in this evaluation.
- When choosing identities during setup, players **cannot choose matching identities**.
- Players _may_ choose a scenario even if one or more villains match one or more chosen identities.

---

## LINKED CARDS (DECKBUILDING)

Cards with the **linked** keyword cannot be included in any deck. Instead, they are **set aside at the start of the game** if any deck includes the card that brings the linked cards into play (indicated in the parentheses following the keyword).

- Linked cards do **not** count toward minimum or maximum deck size.
- The number of linked cards set aside = the number included in the product from which the linked card came.
- If multiple decks contain the same card named on one or more linked cards: set aside the appropriate number of cards for **each deck** that contains the named card.

---

## PERMANENT CARDS (DECKBUILDING)

Cards with the **permanent** keyword:

- Are **not** counted toward a player's minimum or maximum deck size.
- Are **set aside before step 1 of setup** and are put into play later by abilities on other cards.
- Cannot be included in a deck in the traditional sense — they are always set aside.

---

## IDENTITY-SPECIFIC CARDS

- A player's deck must include **each** identity-specific card associated with their chosen identity card, in the **exact quantities** specified by that identity set.
- Identity-specific cards (along with obligation cards and nemesis encounter set cards) may only be used alongside an identity if those cards **share a set icon** with that identity.
- Identity cards are themselves identity-specific cards.

---

## OBLIGATION CARDS

- Identity-specific obligation cards are part of their associated identity's identity-specific set.
- Identity-specific obligation cards can only be used alongside an identity if those cards **share a set icon** with that identity.
- Obligation cards are **not** included in the player deck; they are set aside during setup step 4 and shuffled into the encounter deck during setup step 10.
