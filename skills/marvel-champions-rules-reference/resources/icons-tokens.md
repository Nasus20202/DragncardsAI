## RESOURCE ICONS

| Icon | Name     | Effect                                                                                      |
| ---- | -------- | ------------------------------------------------------------------------------------------- |
| ⚡   | Energy   | Generates 1 energy resource when spent                                                      |
| 🧠   | Mental   | Generates 1 mental resource when spent                                                      |
| 💪   | Physical | Generates 1 physical resource when spent                                                    |
| ★    | Wild     | Generates 1 resource of any type (energy/mental/physical/wild); type chosen when generating |

**Wild resource notes:**

- When generating for a cost: specify type.
- When not generating for a cost: wild only ("cannot be interpreted as other resource types").
- When a card that generates wild resources has its resources doubled: each wild can be declared a different type.

## GAME STATE ICONS

| Icon      | Name                 | Location                       | Effect                                                                                                                                                  |
| --------- | -------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🚀        | Acceleration         | Bottom of encounter cards      | +1 additional threat on main scheme during villain phase step 1 per icon in play                                                                        |
| 🔱        | Amplify              | Encounter cards                | +1 boost icon added to each boost card during enemy activations per amplify icon in play                                                                |
| 💥        | Crisis               | Encounter cards                | Player cards cannot remove threat from the **main scheme** (encounter card abilities unaffected)                                                        |
| ☣        | Hazard               | Encounter cards                | During villain phase step 3: for each hazard icon in play, deal **one player** one additional encounter card (in player order; NOT one card per player) |
| ★ (boost) | Boost                | Bottom-right of encounter card | +1 ATK or SCH to activating enemy per icon (resolved during boost card step)                                                                            |
| ★ (stat)  | Star                 | Next to a stat value           | Reminder: check text box when that stat is used; NOT a boost icon; treated as 0 when referenced                                                         |
| ✦         | Consequential Damage | Beneath ally ATK or THW field  | Ally takes 1 damage per icon after attacking (under ATK) or thwarting (under THW)                                                                       |
| →         | Cost Arrow           | In ability text                | Separates cost from effect: "pay cost -> resolve effect"                                                                                                |
| 👤        | Per Player           | Next to a value                | Multiplies that value by the number of players who **started** the scenario (does not change if player eliminated)                                      |
| ♦        | Unique               | In card title                  | Card is unique; matching unique cards cannot coexist in same deck or play                                                                               |

## TOKENS

### Damage Tokens

- Track damage on allies and minions.
- Placed on card; total value = sustained damage.
- No inherent limit on quantity (use substitutes if needed).

### Threat Tokens

- Track threat on scheme cards.
- No inherent limit.

### Acceleration Tokens

- Functionally equivalent to acceleration icons (but NOT considered acceleration icons, and vice versa).
- Placed next to main scheme as reminder to add +1 threat per token during villain phase step 1.

**Placement sources:**

- Encounter deck empties -> place 1 acceleration token next to main scheme.
- Card effects may also add them.

**Removal rules:**

- On the **main scheme**: cannot be removed from play; not discarded when main scheme advances (carry over to new stage).
- On other cards: removed when that card leaves play.
- Tokens on cards other than main scheme still add threat to main scheme during villain phase.

### All-Purpose Counters

- No inherent rules; defined by the card they occupy.
- Card abilities create named counter types (e.g., "arrow counter", "web counter", "charge counter").
- When moved to another card: lose previous type; gain type defined by new card (or "all-purpose counter" if no type defined).
- Considered **tokens** for all game purposes.
- "All-purpose counter" ability can refer to any all-purpose counter regardless of other types it may have.
- Uses (X "Type") keyword: all-purpose counters placed when card enters play; card discarded when last counter removed (and effect resolves).

### Status Cards (as tokens)

- Stunned, Confused, Tough — see [status.md](status.md).
- No limit on supply; use substitutes if needed.

---

## COMPONENT LIMITATIONS

There is **no limit** to the number of threat tokens, damage tokens, acceleration tokens, status cards, or all-purpose counters that can be in the game at any time. If provided tokens run out, use other tokens, counters, or coins as substitutes.
