# Marvel Champions — Golden Rules, Grim Rule & Component Limitations

**Source:** Rules Reference v1.7 | **Referenced by:** SKILL.md

---

## GOLDEN RULES

### Rule Hierarchy

1. If the text of this **Rules Reference** directly contradicts the **Learn to Play** book → **Rules Reference takes precedence**.
2. If the text of a **card** directly contradicts the **Rules Reference** or **Learn to Play** → **card text takes precedence**.

### "Cannot" Is Absolute

- The word "cannot" is absolute and **cannot be countermanded** by other abilities or effects.
- If two abilities conflict, the ability with "cannot" takes precedence.
- If two rules conflict, the rule with "cannot" takes precedence.
- A **card ability** can override a rule with "cannot" per the Golden Rules hierarchy above.

---

## THE GRIM RULE

If players are **unable to find the answer** to a rules or timing conflict in this Rules Reference:

> Resolve the conflict in the manner that the players perceive as the **worst possible resolution** at that moment with regards to winning the scenario, and continue with the game.

---

## COMPONENT LIMITATIONS

- There is **no limit** to the number of threat tokens, damage tokens, acceleration tokens, status cards, or all-purpose counters that can be in the game at a given time.
- If players run out of the provided tokens, counters, or status cards → **other tokens, counters, or coins may be used as substitutes**.

---

## COMMONLY MISAPPLIED PRECEDENCE CASES

| Situation                                                                                                 | Ruling                                                                                           |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| A card says "cannot be targeted" and an ability tries to target it                                        | "Cannot" wins; the card is not a valid target                                                    |
| A card ability says "deal damage to any character" and another card says a character "cannot take damage" | "Cannot" wins; that character cannot be assigned or take the damage                              |
| Rules Reference says X happens; a card says X does not happen                                             | Card text takes precedence (Golden Rule 2)                                                       |
| Two cards both say "cannot" and they contradict each other                                                | Both "cannots" apply; neither overrides the other — the action is simply not possible            |
| A card ability attempts to override "cannot" via a replacement effect                                     | Replacement effects are card text; card text can override a rule with "cannot" per Golden Rule 2 |
