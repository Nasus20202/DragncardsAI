# Marvel Champions — Modes of Play

**Source:** Rules Reference v1.7 | **Referenced by:** SKILL.md

---

## STANDARD MODE

Basic mode of play. Follow content and setup instructions for the chosen scenario.

---

## EXPERT MODE

For advanced players seeking greater challenge.

- Use listed **expert mode villain stages**.
- Add **Expert encounter set** to the encounter deck.
- Expert set is **NOT** a modular encounter set; cannot be selected when a scenario requires players to choose a modular encounter set.
- Can combine with: Heroic, Skirmish, Campaign.

---

## HEROIC MODE

Scales difficulty by dealing additional encounter cards.

- Before game: player group chooses a **heroic level number** (e.g., 1, 4).
- During villain phase step 3: deal **X additional encounter cards to each player**, where X = chosen heroic level.
- Can combine with: Expert, Skirmish, Campaign.

---

## SKIRMISH MODE (also "Rookie Mode")

Shortens the game by using only one villain stage.

- Before game: player group chooses **any one version of the villain**.
- During setup step 8: put only the chosen villain version into play; **remove all other versions** from the game.
- Can combine with: Expert, Heroic, Campaign.

---

## CAMPAIGN MODE

Interconnected scenarios played one after another.

- Rules for each campaign found in the campaign's **associated rulebook**.
- Each campaign has a **campaign log** tracking effects/cards that persist between games.
- If a card is removed from a campaign: cannot be used for the rest of that campaign (even if players retry the scenario where it was removed).
- Players can choose which other modes to play for each **individual scenario**; campaign mode does not require any specific other mode.
- Can combine with: Expert, Heroic, Skirmish.

### Expert Campaign Mode

- Modification of campaign mode for greater challenge.
- Rules found in campaign's associated rulebook.

### Campaign Mode & Other Modes

- Players may mix modes between scenarios freely (e.g., standard for one, expert for next).
- Difficulty of campaign mode does not lock players into any other mode.

---

## MODE COMBINATIONS

| Mode     | Can Combine With             |
| -------- | ---------------------------- |
| Standard | (base; all others modify it) |
| Expert   | Heroic, Skirmish, Campaign   |
| Heroic   | Expert, Skirmish, Campaign   |
| Skirmish | Expert, Heroic, Campaign     |
| Campaign | Expert, Heroic, Skirmish     |
